# Build CA Foundation Study Tracker V7 APK

This project is ready for Codemagic/GitHub Actions.

1. Push the whole project to GitHub.
2. In Codemagic select the repository.
3. Use the `android-apk` workflow from `codemagic.yaml`.
4. Start a build.
5. Download `app-debug.apk` from Artifacts.

The APK is a debug APK and does not need a release keystore.

For laptop/desktop use, open `web/index.html` in a modern browser.
